This repository contains code for: **Multipath Background learning for Target Detection**.

The dataset is provided as a GitHub Release asset.

## Download
1. Go to the **Releases** page of this repository.
2. Download: **dataset.zip** (or the listed dataset file).

Direct link (recommended):
- Dataset release: https://github.com/YOURUSER/YOURREPO/releases/tag/YOURTAG

## Unzip / Use
### Windows
- Right click the `.zip` → **Extract All…**
- Place the extracted folder in the working directory.
